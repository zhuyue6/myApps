# 目标打卡 0.1

本版替换现有「主/子目标、打卡日历、引导、看板、归档、回收站」。底部三个 Tab 为：**打卡**、**标签**、**我的**。数据存在本地。

一条列表记录是**可反复打卡的计划**，不是单次打卡流水。

## 状态

由系统计算，不可手改。

| 状态 | 条件 |
| --- | --- |
| 进行中 | 当前时间早于计划截止时间，且已打卡次数 < 目标次数 |
| 已完成 | 已打卡次数 ≥ 目标次数 |
| 已过期 | 当前时间晚于计划截止时间，且已打卡次数 < 目标次数 |

「我的」里的已进行数量 = 进行中的计划数。

## 打卡

Tab 页。展示全部打卡计划卡片。没有计划时显示空状态。

每张卡片：

- 名称
- 计划截止时间（年月日时分秒）
- 创建时间
- 周期：日 / 周 / 月
- 完成度：已打卡次数 / 目标次数，以及百分比
- 状态
- 可选标签名；未选标签则不展示

操作：

- 「打卡」：已打卡次数 +1。已完成、已过期不可再打。达到目标次数后变为已完成。
- 点击卡片进入编辑页。
- 删除需二次确认，确认后直接删除，本版无回收站。
- 「新增打卡」进入新增页。

### 新增 / 编辑

同一页面。编辑时回显。

可编辑：

1. 名称，必填
2. 计划截止时间，必填，选择年月日 + 时分秒
3. 周期，必选：日、周、月
4. 目标次数，必填，正整数。这是整条计划的总次数，不按周期清零
5. 标签，可选，从已有标签里选

编辑页额外只读：

1. 已打卡次数
2. 创建时间
3. 状态

保存前校验，不通过时给出对应提示：

- 名称为空
- 未选截止时间
- 未选周期
- 目标次数不是大于 0 的整数
- 目标次数小于已打卡次数（编辑时）

周期只用于展示。本版不按日拆时段、不按周选星期、不按周期自动重置次数。

## 标签

Tab 页。展示全部标签卡片。没有标签时显示空状态。

每张卡片：标签类型、标签名称。

操作：

- 点击卡片进入编辑页，回显后可改。
- 删除需二次确认。已被计划选用的标签删除后，这些计划变为未关联标签，不删除计划。
- 「新增标签」进入新增页。

### 新增 / 编辑

1. 标签类型：从已有类型里选，或输入新类型。必填
2. 标签名称，必填
3. 同一类型下名称不可重复

保存前校验，不通过时给出对应提示。

## 我的

Tab 页。

1. 默认头像
2. 昵称，可本地修改，默认「打卡用户」。不申请微信头像和昵称
3. 进行中的计划数量
4. 已完成的计划数量
5. 已过期的计划数量
